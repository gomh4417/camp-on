# 참여자 기반 지도 이동 시연

차량 앱 함께 이동 지도에서:
1. 실제 그룹에 참여한다. 등록된 참여자만 사용하며 가짜 B/C를 생성하지 않는다.
2. 출발지 선택 → 지도 지점 클릭(또는 지도를 옮기고 지도 중심 선택).
3. 목적지 선택 → 지도 지점 클릭.
4. 함께 이동 → 도로 경로를 따라 닉네임이 표시된 프로필 핀이 이동한다.
5. 일시 정지/계속 이동, 처음부터 다시, 시연 끝내기로 제어한다. 정지 화면 옵션은 다음 위치 보기로 진행한다.

OSM 지도와 Leaflet 1.9.4, OSRM route API 재사용. 경로 거리를 기준으로 약 1분 동안 시각적으로 압축한 이동이며 실제 ETA가 아니다. 동일 출발지에서 그룹원이 순차적으로 출발하는 모습이다. 지도 좌표는 시연 전용이며 서버 목적지·실제 위치·도착 상태·차량 SDK 설정에 쓰지 않는다.

실제 위치 마커와 시연 마커를 별도 레이어로 분리한다. 참여자 변경·연결 끊김 시 기존 시연을 중단한다. 화면 숨김 시 일시 정지. 경로 요청 취소·12초 제한·오류를 처리하며 실패 시 임의 직선 경로로 대체하지 않는다. 확대 화면 전환/앱 재시작 시 시연은 다시 선택한다. 공용 OSRM 서버는 상시 운영 SLA가 없는 외부 의존성이다.

## 검증
- Node 테스트: 실제 참여자 수만 생성, 좌표 경로 요청, 정지 화면 단계 진행, 연결 끊김 중단, 실패 시 가짜 경로 없음.
- 실 OSRM 요청: 강릉의 두 지점 사이 Ok / 8,166.1m / 경로점 221개 응답.
- Android assemble, 단위 16개, lint 통과.
- 프로덕션 서버에 검증용 참여자·메시지를 생성하지 않음.
