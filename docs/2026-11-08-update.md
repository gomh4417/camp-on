# 2026-11-08 UI·모바일 연동 변경

- 탭: 함께 이동 → 에너지 계획 → 캠핑 현황 → 종료·귀가.
- 외부 장비 등록은 에너지 계획 한 곳에서 수행. 캠핑 현황은 등록 장비 선택과 모드별 추천. 같은 종류 여러 장비 중 사용자가 고른 장비의 전력·시간을 사용.
- 집 경로·귀가 에너지·예비량 입력은 종료·귀가에 배치. 에너지 계산은 기존 귀가/예비량을 계속 고려.
- 기존 요리·휴식·취침 그림 복구, 등록/추천/실행 설명은 공통 장비 그림 사용. 캐릭터는 원본 얼굴 사용. Pleos 시스템 좌측 차량·HVAC는 변경하지 않음.
- 기본 액션 72dp, 탭 76dp, 모드 선택 172dp, 장비 선택 152dp 위젯. 시스템 인셋 보존.
- 활동의 “실행”은 계획을 반영하고 차량 적용 확인으로 연결. 선택만으로 물리 제어하지 않음. 기존 주차/권한/최신 관측/부분 실패/복원 제약 유지.
- 모바일 웹: 시작·설정·공동 To-do·대화. PC CAR A + 휴대폰 CAR B/C. 설치 불필요. 사용법은 [mobile-companion.md](mobile-companion.md).
- 차량 연결 시 진행 중 조회를 기다리도록 변경. 조회 중 연결 버튼 입력이 유실되던 문제 수정.

## 검증 결과

- Android assembleDebug, unit 16개, lintDebug 통과.
- Pleos emulator-5554: instrumentation 9개 통과. 선택한 동일 종류 장비 유지, 중복 실행, 재시작, 복원 기존 회귀 검증 포함.
- Node 통합 테스트 2개 통과: 기존 그룹 + 신규 3인 서비스.
- 외부 HTTPS에서 3개 세션 생성, B/C 메시지 2개, 공동 할 일 1개 확인.
- 해당 HTTPS 그룹에 차량 앱 연결 후 B/C 발신 메시지를 실제 그룹 브리핑·대화 화면에서 확인.
- 에너지 장비 그림·탭 순서·캠핑 모드 원본 그림을 Pleos 화면에서 확인.
- 실제 휴대폰 2대 및 모바일 브라우저 시각 검증 미실시. 브라우저 자동화 사용 중단으로 해당 부분 확인 불가.
- Vercel 임시 배포는 403으로 접근 차단. 정식 배포 인증 미완료. 대체 HTTPS 웹은 PC 서버·터널 가동 중 사용 가능.
- 실제 차량 물리 작동·전력 사용량은 이번 변경에서 재검증하지 않음.
- Graphify 로컬 AST 증분 갱신. 일부 Kotlin 문법 부분 분석 경고가 있어 컴파일·테스트를 기준으로 판단.
