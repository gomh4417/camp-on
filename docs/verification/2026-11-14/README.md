## 검수 범위와 판정

- 화면의 고정 구조·색상·타이포그래피를 비교했다. 전체 화면의 픽셀 단위 완전 일치를 인증한 결과는 아니다.
- Figma의 임의 차량 그림은 요청받은 원본 GIF로 교체했다.
- 시안에 고정된 배터리·온도·시간·상태는 실제 값 또는 계획 계산값으로 표시한다. 관측되지 않은 외부 온도는 —, 요청값은 관측값으로 대체하지 않는다.
- 장비 사용 스위치는 에너지 계획을 바꾸며 외부 가전제품의 실제 전원을 켰다고 표시하지 않는다.
- 모바일은 제공된 차량 시안의 색상·서체·카드·버튼을 사용한 반응형 구성이다. 원본 모바일 Figma 시안은 없다.
- Android 캡처는 별도 테스트 세션/VehicleSource로 만든 시각 검증 자료다. 실제 SDK 증거는 별도 로그에 있다. 운영 그룹·메시지에 테스트 참여자를 넣지 않았다.

## 화면별 공통 10가지 체크리스트

1. 기준 화면의 주요 영역·드로어 위치·정렬을 반영했는가.
2. Asta Sans, 색상, 글자 크기와 위계가 일관적인가.
3. 차량 피사체가 제공 원본으로 유지되고 해당 시간대 장면을 사용하는가.
4. Pleos 시스템 영역과 앱 인셋을 침범하지 않는가.
5. 검증 해상도에서 텍스트·버튼·입력값이 잘리거나 겹치지 않는가.
6. 화면 진입·닫기·주요 버튼이 기존 세션/기능에 연결되는가.
7. 빈 값·잘못된 수치·취소·삭제 등 해당 화면의 입력 경계를 처리하는가.
8. 실제 관측, 요청 대기, 예상 에너지, 미상값을 구분하는가.
9. 계획·정지 화면·장비 사용 상태를 저장하고 세션 규칙을 유지하는가.
10. 해당 차량 명령을 SDK 전송 → 재조회 → 원래 값 복원으로 검증했는가.

범례: **통과**=기재된 환경/범위에서 확인, **해당 없음**=그 화면이 해당 기능을 갖지 않음, **보류**=성공 증거 부족. 화면 캡처 성공만으로 SDK 체크를 통과 처리하지 않는다. 큰 글꼴/실차/물리 휴대폰 전체 조합은 미검증이다.

## GIF 시간 규칙

기기의 현지 시간 기준: 05:00~10:59 새벽/아침, 11:00~15:59 낮/오후, 16:00~18:59 오후/해질녘, 19:00~04:59 저녁/밤.

인접 시간대로 넘어갈 때 transition GIF 한 번(각 200프레임/10초) → 새 시간대 loop 무한 반복. 첫 실행·백그라운드 복귀·시간을 여러 구간 건너뛴 경우 현재 loop부터 표시한다. 정지 화면 선택 또는 기기의 동작 줄이기를 존중한다. 원본 파일은 수정하지 않았다.

- Android: 4개 transition의 실제 종료 콜백, repeatCount=0, loop 무한 반복/정지 확인.
- 웹: 4개 경계 시간을 브라우저 시계로 진행해 transition → loop → loop 유지 확인.
- 시간대 경계와 비연속 전환: 단위 테스트.
- 앱의 화면 시계와 GIF가 같은 기기 시간대를 사용한다.

## SDK 제한

Virtual Console을 열어 둔 상태에서 명령이 차량 상태에 반영되는 것을 확인했다. 콘솔이 닫힌 최초 시험에서는 SDK 수락과 실제 반영이 달랐다. 앱은 이런 값을 성공한 관측값으로 표시하지 않는다.

최종 시험은 25개 중 21개 변경·재조회 확인, 복원 미해결 항목 0개다. 이전 실패 시험의 기록도 원래 값을 직접 재조회하여 일치하는 경우에만 정리했다.

등받이 위치 4개는 에뮬레이터에서 값이 움직이지 않았다. 앱은 ‘시트 이동 확인 불가’를 표시하고 STOP을 전송한다. 전부 정상 작동으로 판정하지 않는다. 풍량은 공조 전원이 켜진 상태에서 검증해야 하며, 꺼진 상태에서는 SDK가 거부할 수 있다.

## 실행

Android Studio Run은 Android 앱을 실행한다. 모바일 웹 서버와 터널은 별도 프로세스다.

```powershell
node services/group-sync/companion.mjs
& "$env:LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe" forward tcp:8088 tcp:8088
Start-Process "http://127.0.0.1:8088/"
```

휴대폰은 현재 Cloudflare HTTPS 터널 주소로 접속한다. PC·서버·터널이 계속 켜져 있어야 한다. Vercel 영구 배포 완료로 표시하지 않는다. 그룹 데이터와 토큰은 기존 로컬 저장소를 유지하고 Git에서 제외한다.
